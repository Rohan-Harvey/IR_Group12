# LIMO model resources

The body and wheel meshes come from the [AgileX LIMO ROS 2 repository](https://github.com/agilexrobotics/limo_ros2), Humble branch. The original Xacro files and upstream documentation are in `source/`. The simulation uses a uniformly scaled model with a straight-ahead width of 2.12 m.

This project adapts the SDF model, collision geometry, dynamics, sensor interfaces and Ackermann drive plugin for Gazebo Harmonic.

The upstream `limo_car` package declares Apache 2.0. See [the model licence](LICENSE.apache-2.0) and [the project licence](../../LICENSE).
